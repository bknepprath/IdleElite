# Navigation Control Icons

Approved UI icon assets for the upcoming module controls update.

- `sort-list.png` - utility row Sort button.
- `skills-overview.png` - utility row Skills / all-skills overview button.
- `pin.png` - Pinned utility button, temporary pin confirm badge, and pinned-state badge. On modules, use the pin icon without a circle; bury the tip into the card surface.

Current menu plan:

- Utility row above chat: Pinned, Skills, Sort.
- Module actions: invisible top-left Pin zone and invisible top-right Collapse zone. Each uses a two-stage confirm.
- Confirmed pins use a short anticipation animation before poking into the top-left card corner.
- Sort starts with Level order and Reverse level order. Module type sorting is deferred until module type metadata exists.
- Bottom gray navigation bar: five main navigation buttons.

Collapse does not have an approved generated icon yet. Rejected generation drafts were removed from the workspace.
