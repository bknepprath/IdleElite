1. Page Switch

Every skill page ends with two buttons: previous skill and next skill. The buttons use the destination skill color.

2. Module Menu

Every module gets one small menu button in the same spot. The menu contains Pin, Favorite, and Collapse.

3. Bottom Dock

Add four buttons above chat: Favorites, Sort, Skills, and Ready. Keep labels short and readable.

4. Spacing

Add bottom padding to scroll pages so the dock and chat never cover the final module.

Button Rules

FavoritesShows favorited modules. Gold while active.
SortSort by level order or module type.
SkillsReturns to the skill hub.
ReadyJumps to the active or reward-ready module.

Module State Rules

PinMove module to the top of this page.
FavoriteAdd module to the Favorites view.
CollapseShrink module, but keep it visible.
SortSort normal modules. Pinned modules stay first.
