Main Checklist

  1. Generate first-pass UI icons.Created transparent PNG drafts for Favorites, Sort, Skills, Ready, Module Menu, Pin, Collapse, Move To Top, and Future.Done: icon drafts are shown above and saved in docs/assets/ui-navigation-icons/.
  2. Find the shared module render paths.Identify every place modules are built, including skill detail pages, fishing area modules, passive/collect modules, and any special event modules.
  3. Define stable module keys.Create a consistent key format for pin, favorite, collapse, and sort state. Do not use display names as IDs.
  4. Add save data for module UI preferences.Store pinned modules, favorites, collapsed modules, and sort mode separately from activity progress.
  5. Add one module menu button to every module.Use the same corner and same visual style everywhere. The button opens actions for that module.
  6. Build the module dropdown.The dropdown must include Pin, Favorite, and Collapse. It should close cleanly after selection or outside tap.
  7. Implement Pin.Pinned modules move to the top of the current page. Pinned modules keep their normal behavior.
  8. Implement Favorite.Favorited modules are added to the Favorites view and can be removed from the same menu.
  9. Implement Collapse.Collapsed modules shrink to a compact row but remain visible and expandable.
  10. Add the bottom dock above global chat.Dock buttons: Favorites, Sort, Skills, Ready. Use dark readable text on light buttons.
  11. Add safe bottom spacing to scroll pages.At max scroll, the final module must not be hidden behind the dock or chat strip.
  12. Build the Favorites view.Favorites opens from the dock. Pressing Favorites again exits the view.
  13. Build the Sort menu.Sort modes: level order and module type. Pinned modules stay above sorted modules.
  14. Move Skills navigation into the dock.The Skills button returns to the skill hub from skill pages.
  15. Build the Ready button behavior.Ready jumps to the active action first, then reward-ready modules, then newly important modules.
  16. Define the skill page neighbor order.Use a single ring order for page switching so every page has a previous and next destination.
  17. Add page switch module to skill pages.The final module on each skill page has two destination-colored buttons.
  18. Block accidental input behind dock menus.Dock taps, dropdown taps, and menu taps must not start swipes or press modules underneath.
  19. Refresh visual states after changes.Pin, favorite, collapse, sort, and favorites mode should redraw immediately without needing a full restart.
  20. Run project validation.Use .\scripts\check-project.ps1 and follow Godot process safety rules.
  21. Manual layout pass on a long page.Inspect a long skill page at max scroll and confirm the bottom module, dock, and chat do not overlap.
  22. Manual layout pass on a short page.Confirm the dock still sits naturally above chat when there is not much page content.
  23. Update this checklist.Check off every completed item and add notes for anything deferred.
