Current Rules

  • Max stamina = base stamina + cumulative level bonus + global medal/achievement bonuses + per-skill medal bonus.
  • Every 10 cumulative skill levels adds +1 max stamina to every skill.
  • Every 3 medals earned inside a skill adds +1 max stamina to that skill.
  • The Godot UI renders side gauges on the skills menu and action-card cost feedback in skill detail.
