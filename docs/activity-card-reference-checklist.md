# Activity Card Reference Checklist

- [x] Normal activity face uses farm art clipped to the rounded face.
- [x] Face outline uses a thicker, smooth black stroke.
- [x] Normal activity card has a dark red 3D body/base.
- [x] Red body is attached to the bottom/right of the face, not a detached underline.
- [x] Bottom-left and top-right connector gaps are filled by solid red diagonal faces.
- [x] Action art panel has a black outline.
- [x] Normal-card stat layout uses compact two-row text with XP included.
- [x] Normal-card bottom progress rail is wall-to-wall, red, and driven by action_progress.
- [x] Non-recovery mastery progress is hidden as a separate horizontal bar.
- [x] Art-panel mastery ring wraps the square art panel and is driven by mastery percent.
