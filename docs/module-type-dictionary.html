Resource Module

Shows stored output. Tools are unlocks, not spendable resources.

Hard Resource Physical things used to make other things: softwood logs, hardwood logs, ore, rich ore, pristine ore, ingots, refined ingots, animal parts, food, leather, planks.
Soft Resource Abstract progress or readiness: grit, focus, knowledge, secrets.
Tool One-time unlock that persists and enables new actions or improves existing actions: kiln, ice bath, steam lodge.
