## Open Decisions Logged

- Buildable availability: prototype modules appear at their unlock level, even if the player cannot yet afford the cost. This keeps the goal visible.
- Build XP target: prototype grants XP to the module owner skill.
- Recovery cost model: prototype uses low/no stamina cost plus opportunity cost from poor XP, then reassesses.
- Boss gates: prototype blocks only modules that explicitly reference the boss or sit behind an explicit gate field, not every later list item by accident.
- Berry Prep: prototype consumes one serving on one completion.
- Berry effects: prototype uses one universal berries resource for v0.5.0.
