Implementation — in order

Suggested Godot + data phases. Each step should pass .\scripts\check-project.ps1.

  1. Phase A — Data foundation
    • Add fishing.tools[], areas[].locations[], fishing.affinity{} to activity-database.json
    • Unlock Lvs: Beach shallows 1, rocky 5, Pier module 7, Space module 90 (full table below)
    • Save: equipped_tool_id, fishing_rocky_net_found, last location per region
    • Sync JS: python scripts/sync-activity-database-js.py
  2. Phase B — Gear wallet + tool splay
    • Replace fish-only HUD with button: fish count + equipped tool thumb + chevron
    • Vertical tool list; hide until discovered/crafted; padlock / “craft” rows
    • Affinity chip for active location (tool × spot)
    • Reference mock: fishing-rework-brainstorm.html
  3. Phase C — Location tiles (Beach + Pier)
    • Region module shows 1–3 location thumbs (not methods)
    • Attempt = equipped tool × selected location (affinity multipliers)
    • XP/yield chips from resolved pair, not fixed action row
  4. Phase D — Rocky net discovery (Lv 5)
    • First tap beach.rocky: no attempt — insert zoom module under Beach
    • Click discarded net → fly to wallet → toast “Net collected!” → unlock net tool
    • Later Rocky taps = normal fishing
  5. Phase E — Roll out regions
    • River → Lake → Boat → Reef → Storm → Deep → Space (unlock table)
    • Remove legacy per-area method grouping in main.gd
  6. Phase F — Crafting & passive
    • Craft recipes unlock tools in splay (line, spear, rowboat, …)
    • Lobster cage: passive collect module at Reef Lv 40 (not a location tile)
    • Hook into existing craft benches (woodworking / smithing / TBD)
  7. Polish (can trail v1)
    • JSON fish_min / fish_max on all spots (not tier guess)
    • Archetype art sway on active location
    • Shiny fish on catch pop
    • Mismatch flavor text (“empty net”, “overkill”, etc.)
