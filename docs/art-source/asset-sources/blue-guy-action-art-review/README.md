# Blue Guy Action Art Review

Generated proposals for `docs/blue-guy-action-art-review.html` live here.

Runtime replacement assets should only move into `assets/content/**/actions/` after review. Keep generated proposals versioned with the pattern:

`<skill-id>-<action-id>-v<number>.png`

The review page currently looks for `v1` proposals by default.

## Blue Guy Source Of Truth

Use `docs/art-source/asset-sources/blue-guy-action-art-review/blue-guy-source-of-truth.png` as the first comparison file for every generated proposal.

The sheet defines the correct blue guy body language: compact, rounded, toy-like, simple, and consistent across poses. Any new action proposal should look like one of these poses was adapted to a prop/action, not like a new character design.

## Blue Guy Proportion Rule

The source-of-truth sheet and old action icons define the approved proportions. New proposals must keep the original blue guy dimensions:

- Compact upright cobalt-blue stick figure.
- Small round head, short simple arms, short legs, and a simple rounded torso.
- Rounded mitten-like hands with no fingers.
- Thick black outline and minimal internal detail.
- Props can change, but the blue guy silhouette should stay consistent across actions.

Reject any proposal that turns the blue guy into a tall mascot, realistic person, long-limbed figure, crouched bodybuilder, glossy 3D character, or oversized-head cartoon. Compare against the source-of-truth sheet first, then these action anchors:

- `assets/content/build/actions/02-patch-fence-with-confidence.png`
- `assets/content/build/actions/03-hammer-one-suspicious-nail.png`
- `assets/content/fight/actions/01-shove-wobbly-hay-bale.png`

## Personification Rule

Do not add faces, eyes, mouths, expressions, monster features, or emotional personality to props in fresh generations unless the action concept truly needs it and the current/source icon already makes that personification central to the joke.

Default to non-personified props. Make the action read through blue guy's pose, contact points, impact marks, motion, splashes, tilted objects, broken parts, or clear construction/fight staging.

Acceptable personification examples: an explicitly named angry/stubborn/opponent object where the current icon already uses a face as the core read. Even then, keep it simple and avoid making the prop look like a character that competes with blue guy.
