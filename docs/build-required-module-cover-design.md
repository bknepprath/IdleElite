# Build-Required Module Cover

## Intent

Build-required modules should look physically boarded over, not like a small badge on top of a normal card.

## Layout Rules

- Boards span nearly the full module width.
- Boards sit above the mastery bar and action controls.
- It is okay if the module title peeks through board gaps.
- The player-facing build copy sits above the boards.
- Each board is a separate sprite/node so it can fall independently.

## Text Rules

- Main build label: at least 100 px.
- Main build label outline: at least 30 px.
- Cost and reward text: at least 58 px.
- Cost and reward outline: at least 18 px.
- If the text feels subtle, the outline is too thin.
