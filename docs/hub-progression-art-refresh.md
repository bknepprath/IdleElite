# Hub progression art refresh

## Contract

Six static transparent facility sheets, each 1536 × 1024 with five 512 × 512 states and one empty cell. Construction state then levels 1–4, read left to right. All use thick black outlines, simple broad shapes and cumulative functional upgrades. Ground baseline is authored at cell y450. Runtime draw boxes are fixed per facility, never calculated from image alpha.

Style anchors: `assets/content/hub/hub-tree-sheet.png` and `assets/content/hub/hub-decor-sheet.png`. Earlier in-game captures provide subject and placement context only.

Progressions: barn → storage wing → silo; planted garden beds → trellis → fence; pond → dock → rail/reeds → fishing shelter; notice board → wider board → roof → shelf; wooden dummy → padding → helmet/shield → breastplate/sword; log totem → stacked logs → axe → canopy/second axe.

No gameplay, save ID, cost or bonus changes. Facilities remain separate from hub ground, paths and decoration; no animation or effects are embedded.

## Saved assets

All six PNGs are saved in `assets/content/hub/` under their existing `hub-*-tiers.png` paths: `barn`, `garden`, `fish-pond`, `mission-sign`, `fighting-display`, and `woodcutting-totem`.

The runtime uses fixed authored square draw boxes: barn 350px, garden 310px, pond 360px, mission board 290px, dummy 180px, totem 300px. A shared offset of 194px in the source cell grounds y450 relative to its center. Tier growth comes from authored silhouettes rather than changing runtime scales. Old per-tier offsets and the old pond's obsolete shape bounds are removed.

The dummy was reduced from 280px to 180px after the owner's scale review. The trophy-table audit also found that each trophy's native 256px texture minimum overrode its intended 157.5px draw box. Setting `EXPAND_IGNORE_SIZE` before sizing restores the authored size and tabletop placement for all four trophies.
