Novice dip

novice

Fishing Lv 1 tutorial: one minnow, one pop, one currency. Believably clumsy, still rewarding.

  • Bar Smooth fill, extra-long calm
  • Timing ~62% calm · short bite
  • Success ~92%
  • Catch Fixed 1 fish (1:1 with HUD)
  • Fail Soft miss, no punishment stack

Reliable line

steady

Default idle rhythm. Patient calm, readable bite, normal yield band. Most methods use this.

  • Bar Smooth linear fill
  • Timing 55% calm · 88% bite (baseline)
  • Success ~82%
  • Catch Tier-based min–max pops
  • Fail Standard miss

Net haul

volume

The net type. Drag mesh, snag something, spill fish out — not a bobber fantasy. Stepped bar sells pull strokes.

  • Story Drag → snag → spill (not calm / bite)
  • Bar Stepped ticks (4–5 chunks)
  • Timing Short drag · quick snag band
  • Success ~78%
  • Catch +1 fish roll often; faster pop stagger
  • Fail “Empty net” — not “got away”

All-in strike

commit

Long setup, one sharp moment. Bar crawls, then surges in the bite window.

  • Bar Late surge to 100%
  • Timing ~72% calm · short bite
  • Success ~70%
  • Catch Fewer pops, bigger spacing
  • Fail Harder whiff on reveal

Sewer grab

chaos

Unreliable and janky. Jitter bar, lower success, high variance when it hits.

  • Bar Jitter wobble on fill
  • Timing Medium calm · unstable bite
  • Success ~62%
  • Catch Low min, spicy highs rare
  • Fail Common — “slipped away”

Chum gamble

risk

High upside, zero on fail. Bite phase feels dangerous; miss means no fish at all.

  • Bar Smooth + caution bite tint
  • Timing Medium calm · warned bite
  • Success ~68%
  • Catch High max yield
  • Fail 0 fish (not low roll)

Implementation (game)

Live in Godot with FISHING_REWORK_ENABLED. Areas: beach → pier → river → sewers → lake → reef → boat → deep → storm → space. Mock modules below still say offshore / cosmic naming in places — see fishing-rework-status.md for shipped vs deferred.

Direction — pick your tool

Unlock places and tools separately. At any unlocked area, use any unlocked tool — affinity sets success/yield/speed, not a hard ban. Bare hands → one beach minnow; later a net; later a harpoon you can use on minnows (terrible idea). Same joke in reverse: hands in space, boat in a tide pool.

UI: tap fish wallet → tools splay vertically (crafted unlocks). Region cards = location spots only.

Spec: fishing-tool-area-matrix.md. Beach below is the target; other regions may still show legacy method arts.

Locked

No stamina Fish HUD
  • Other skills: whole module level-locked (chains + padlock on card).
  • Fishing: each method has its own unlock level.
  • Fishing lock UI: padlock on the art tile only — no chains.
  • Show one locked teaser at a time (next method globally).
  • Hide all other future locked methods until they become that teaser.
  • Data: each action has area; fishing.areas[] is module metadata (order, bg, fluid).
  • Target: region module = 1–3 location spots (not tool arts); mastery on tool rack.
  • Legacy shipped UI: 1–3 method arts per area until migration.
  • Right column: XP + yield only (no time/success).
  • Running fluid: hybrid strip (wave layers + scrolling foam tile); tint per area (data-fluid).
  • No action bar — same seconds timer as other skills, hidden; fluid + phases show progress.
  • Attempt readout: archetype picks the story (line: wait/bite/land; net: drag/snag/spill). Flat XP each attempt; fish only on success (min–max).
  • Success juice: one roll, then pop pop pop fish icons (burst UI, not extra rolls).
  • Method archetypes (#4): each method has its own timing + rules (net / rod / harpoon / …).
  • Shiny fish (#6): ultra-rare variant on a pop — collection / sparkle moment.
