Combo Unlocks, Colored Locks, and Event Modules

Ordered implementation plan for the new lock ceremony, multi-skill requirements, combo XP, temporary event modules, and the asset work that supports them.

Make locked modules feel physical, readable, and worth chasing.

The goal is to keep the existing activity-card feel, then add requirement-colored locks, multi-lock layouts, player-click unlock drops, combo skills, multi-color XP rewards, temporary event modules, and a wider level-80 mono-skill runway.

Lock Renderer

scripts/activity_lock_rig.gd owns the chain physics, cropped padlock hit mask, click input, clink/rattle behavior, and current falling unlock animation.

Action Cards

scripts/main.gd builds normal and swipe-preview cards, then attaches a single lock_overlay when _is_action_unlocked is false.

Source Data

docs/activity-database.json is the action source of truth. The loader currently preserves basic fields like unlock, xp, stamina, and art paths.

XP Feedback

The active action loop adds one XP integer to the running skill, then _float_xp shows one green popup. Combo XP needs a reward map.

Current Data Assumptions Frozen

Before the combo unlock work starts, the current runtime assumptions are: each action belongs to one owning skill page, normal actions expose one numeric unlock level, the loader preserves one primary xp value, playable state is stored through one manual unlock key per action, and action-card lock overlays currently assume one lock rig per locked module. Future steps should change these assumptions deliberately through normalized requirements and reward maps.

Core Behavior Target

A module can be blocked by one or more skill locks. Unmet locks are closed and skill-colored. Once a requirement is met, that specific lock clinks open but stays holding the chain. The module remains covered until every requirement is met and the player clicks the ready lock cluster. Then the lock or locks fall away, the shade clears, and the module becomes usable.

Recommended First Implementation Slice

Do not start by generating every combo asset. Start with the data/helper split, a single two-lock combo using placeholder existing art, and colored XP popups. Once the unlock states and reward maps are stable, produce the lock parts and first real combo asset sheet. That keeps the hardest system risk in front, where it belongs.
