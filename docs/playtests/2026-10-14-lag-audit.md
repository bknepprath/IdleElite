# Lag audit, October 14, 2026

## Changes

- `scripts/gameplay/activity_unlock_runtime.gd`: resolve Fishing's one visible locked teaser once per query. Previously every locked location queried visibility by searching the entire progression list again. No persistent cache or delayed invalidation is used; same-frame resource, Wisdom and tool changes take effect immediately.
- `scripts/ui/skill_detail_surface.gd`: count construction of a cached card against the current frame's work budget. Previously a failed immediate mount could successfully build its cached replacement and still remove another card in the same frame.
- `scripts/app/lifecycle_runtime.gd`: traverse existing animation metadata instead of calling every cleanup function on every static descendant. Restore reveal geometry only on controls that participated in a reveal. Decorative opacity and unrelated tweens now survive cleanup.

## Measurements

All Godot runs used the safe wrapper, isolated saves and muted monitoring. Timing runs were serial. No release export was created. The active checkout is `.codex-tmp/worktrees/idle-elite-1080p` under the primary project.

The matched traced Fishing scrolling samples improved from **11.86 ms average to 5.01 ms average**, a **58% reduction**. Its p99 improved from 20.40 ms to 15.71 ms. The deterministic unlock-query comparison evaluated 1,008 states, including 462 available-unlock cases: identical results, 5.578 seconds in the reference versus 0.338 seconds in the optimized implementation, approximately 16.5 times faster. Whole-game timings vary with background load and include instrumentation overhead.

The final untraced headless stress pass:

| Skill | Idle p99, ms | Scroll average, ms | Scroll p99, ms | Scroll maximum, ms |
| --- | ---: | ---: | ---: | ---: |
| Thieving | 2.04 | 5.36 | 13.23 | 27.06 |
| Building | 1.98 | 5.19 | 15.97 | 34.18 |
| Fighting | 2.46 | 5.75 | 12.00 | 17.01 |
| Fishing | 1.95 | 3.64 | 13.66 | 14.77 |
| Woodcutting | 2.28 | 4.37 | 10.33 | 14.31 |

This is **not a full performance-gate pass**. Thieving and Building exceed the 22 ms maximum scrolling budget; ordinary swiping has 15/552 samples over the 120 FPS budget (allowed: 10). Rapid swiping passes. All five idle pages pass. Fishing and Woodcutting have zero scrolling frames above 16.667 ms in the final pass. These measurements are headless frame work, not browser/GPU frame rates.
